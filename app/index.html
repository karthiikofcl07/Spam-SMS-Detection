Process

End-to-end NLP pipeline

Five stages transform raw SMS text into a binary verdict in milliseconds.

01
Raw input

Any SMS message enters the pipeline as unstructured text from the SMS Spam Collection dataset — 5,572 real messages, 86.6% ham and 13.4% spam.

dataset · 5,572 records · UCI ML repository
02
Preprocessing

Lowercased. URLs normalised to a url token. Digits replaced with num. Punctuation stripped. Whitespace collapsed. Spam messages average 138 chars vs 71 for ham.

re.sub · str.lower · url_tag · digit_tag
03
TF-IDF vectorisation

8,000-feature bigram matrix with sublinear term-frequency scaling. Captures single words and two-word spam patterns like "free entry" and "call now".

max_features=8000 · ngram_range=(1,2) · sublinear_tf=True
04
Model training

Three classifiers trained on an 80/20 stratified split — Naïve Bayes, Logistic Regression, and SVM — each benchmarked with 5-fold cross-validation.

MultinomialNB · LogisticRegression · LinearSVC
05
Verdict

SVM wins as the best model across all metrics. Ham or spam output in real time, validated by stratified cross-validation with a mean F1 of 95.54% ± 0.79%.

LinearSVC · 98.92% acc · F1 95.97% · CV 95.54±0.79%
